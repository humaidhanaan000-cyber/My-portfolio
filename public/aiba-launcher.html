3 · Start the app (one double-click)

In the project folder there are three start files. Use the one for your system — each of them installs dependencies the first time, starts the web app together with the agents, waits until the server answers, and then opens your browser by itself.

Windows — start-aiba.bat
  1. Install Node.js 22 or newer once: nodejs.org.
  2. Open the project folder and double-click start-aiba.bat.
  3. A black window opens with the server logs — leave it open; your browser opens automatically.
  4. To stop the app, close that window (or press Ctrl + C in it).
macOS — start-aiba.command
  1. Double-click start-aiba.command in Finder.
  2. The first time, macOS asks for permission — right-click → Open → Open confirms it.
  3. A Terminal window shows the logs and your browser opens by itself. Close the window to stop.
Linux — start-aiba.sh
  1. Make it executable once: chmod +x start-aiba.sh.
  2. Run ./start-aiba.sh (double-click also works in most file managers).
  3. Press Ctrl + C to stop.
Any system — the command line version 
cd path/to/My-portfolio
cp .env.example .env      # first time only; set AUTH_SECRET
npm install               # first time only
npm run agent             # builds, migrates, starts web + agents

Then open http://localhost:3000. With Docker instead: docker compose up -d --build.

4 · First five minutes in the app

  • 1 Create an account, or sign in as the administrator.
  • 2 Finish the five onboarding steps — profile, risk tolerance, budgets, monetisation, automation level (keep approval required).
  • 3 /dashboard/opportunities → analyse one, then build a strategy.
  • 4 /dashboard/approvals → approve it; the workflow then executes on its own.
  • 5 /dashboard/revenue and /dashboard/expenses → add one manual entry each and watch net, margin and ROI update.

The dashboard reads DEGRADED until an AI provider key is configured; every job still runs with the deterministic agents. Report and audit pages live under /dashboard/reports and /dashboard/admin.

This file is self-contained: no internet connection, no build step, no installation. Keep it next to the project (or open /aiba-launcher.html from the running app).
